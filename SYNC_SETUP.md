# Автоматическая синхронизация памятки «Банки России 3.0»

Источник: https://docs.google.com/spreadsheets/d/1BIwMWMBAB7LR9MbR5qGrIXYbq_LdFshCPz1Q_l-Mqcs/edit

Сайт: https://strana-ipoteka.github.io/mortgage-knowledge-base/memo-original.html

## Однократная настройка (без передачи секретных ключей в чат)

1. Откройте [Google Cloud Console](https://console.cloud.google.com/), создайте проект, включите **Google Sheets API**.
2. В разделе **IAM & Admin → Service Accounts** создайте сервисный аккаунт. Создайте для него ключ типа JSON и скачайте его локально. **Не загружайте JSON в GitHub как файл и не отправляйте в чат.**
3. В исходной Google Таблице нажмите **Поделиться** и выдайте email сервисного аккаунта доступ **Читатель**. Для работы также должно быть разрешено чтение нужных вкладок. Если доступ сервисному аккаунту запрещён корпоративной политикой, согласуйте способ с администратором.
4. GitHub → [Settings → Secrets and variables → Actions](https://github.com/strana-ipoteka/mortgage-knowledge-base/settings/secrets/actions) → **New repository secret**. Имя: `GOOGLE_SHEETS_SERVICE_ACCOUNT_JSON`. Значение: **полное содержимое JSON-ключа**, не путь к файлу.
5. GitHub → [Settings → Actions → General](https://github.com/strana-ipoteka/mortgage-knowledge-base/settings/actions) → **Workflow permissions** → разрешить **Read and write permissions** (если настройка доступна).
6. Откройте вкладку [Actions](https://github.com/strana-ipoteka/mortgage-knowledge-base/actions), выберите **Sync Bank Memo from Google Sheets** и нажмите **Run workflow**. Проверьте журнал: в нём по каждому разделу будет количество обновлённых данных.

По расписанию обновление выполняется по будним дням в 05:15 и 11:15 UTC (08:15 и 14:15 UTC+3). GitHub Actions может запускать задания с задержкой.

## Ограничения и контроль качества

Это **первый этап автоматизации**, а не гарантированный импорт всех данных 1:1 при любом изменении структуры таблицы. Скрипт сохраняет исходное оформление, названия разделов и фильтры, а данные обновляет по сопоставлению банков и подписей столбцов. Если структура вкладки изменилась, отдельные элементы могут остаться прежними. Журнал показывает разделы без найденных совпадений, поэтому его нужно проверить на первом запуске. Не применяйте обновления ставок без сверки с источником; тестируйте на отдельной ветке перед рабочим использованием.

Вкладка **Контакты банков** по умолчанию исключена из автоматического обновления из-за персональных данных. Существующая оригинальная копия этой информации уже находится в публичном репозитории; для неё рекомендуется ограничить доступ или согласовать публикацию.

Скрипт не изменяет исходную Google Таблицу и не сохраняет ключи доступа в файлах сайта.
